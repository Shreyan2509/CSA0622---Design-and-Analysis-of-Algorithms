## 📖 About

**Design and Analysis of Algorithms (DAA)** is a foundational computer science course focused on developing the ability to design efficient algorithms and rigorously analyze their time and space complexity. This repository serves as a central record of coursework for **CSA0622**, including:

- Algorithm implementations across multiple design paradigms
- Time and space complexity analysis of algorithms
- Course Outcome (CO) based assessment task submissions
- Practice problems and their solutions with explanations

## 📚 Course Topics Covered

This repository reflects concepts typically covered in a DAA curriculum, including:

| Category | Topics |
|---|---|
| **Complexity Analysis** | Asymptotic notations (Big-O, Big-Ω, Big-Θ), time & space complexity, recurrence relations |
| **Design Paradigms** | Divide and Conquer, Greedy Algorithms, Dynamic Programming, Backtracking, Branch and Bound |
| **Searching & Sorting** | Linear/Binary Search, Merge Sort, Quick Sort, Heap Sort |
| **Graph Algorithms** | BFS, DFS, Dijkstra's Algorithm, Kruskal's & Prim's Algorithm |
| **Problem Complexity Classes** | P, NP, NP-Complete, NP-Hard problems |
| **Optimization Techniques** | Space-time tradeoffs, algorithmic efficiency improvements |

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/Shreyan2509/CSA0622---Design-and-Analysis-of-Algorithms.git
cd CSA0622---Design-and-Analysis-of-Algorithms
```

### Navigate to a Topic Folder

```bash
cd "Time Complexity"
```
or
```bash
cd CO2_AT2
```

### Run an Implementation

Depending on the language used in a given file:

```bash
# For C/C++
g++ filename.cpp -o output && ./output

# For Python
python filename.py

# For Java
javac Filename.java && java Filename
```

## 🧭 How to Use This Repository

1. Browse the folder relevant to the topic or assessment you're studying.
2. Review the problem statement (if included) alongside the implementation.
3. Trace through the code to understand the algorithmic approach used.
4. Compare theoretical complexity with the implementation logic to reinforce understanding.
5. Use the examples as a reference for similar problems or as a revision resource before exams.

## 🎯 Learning Outcomes

By working through this repository, the following outcomes are reinforced:

- Ability to analyze algorithms and determine their time/space complexity
- Ability to choose the right algorithmic design paradigm for a given problem
- Practical implementation experience translating theoretical algorithms into working code
- Improved understanding of efficiency tradeoffs in algorithm design
