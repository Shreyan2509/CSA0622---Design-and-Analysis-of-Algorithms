## 📖 About the Course

Design and Analysis of Algorithms (DAA) focuses on:

- Asymptotic notations (Big-O, Big-Ω, Big-Θ) and complexity analysis
- Algorithm design paradigms: Divide and Conquer, Greedy, Dynamic Programming, Backtracking, Branch and Bound
- Searching and sorting algorithms
- Graph algorithms (traversal, shortest path, minimum spanning tree)
- Problem classification: P, NP, NP-Complete, NP-Hard
- Space-time tradeoffs and algorithmic efficiency
